Design and Development of an AI Facilities Management User Interface

Mighty Muscle Facilities Management

Project Overview

This capstone project focuses on the design and development of a web-based user interface (UI) for an AI-driven facility management platform. The prototype demonstrates how facility managers can proactively identify asset risk, reduce downtime, and centralize facility data through a single intuitive dashboard.

Project Scope

  • UI-only prototype for an AI facility management platform
  • Simulated AI insights using mock and synthetic data
  • Standalone frontend application built for demonstration and evaluation

Core User Experience

  • Users log in and view a dashboard summarizing facility-wide risk
  • High-risk assets are prioritized with clear recommended actions
  • Users drill down into asset lists and individual asset details
  • Role-aware UI for facility managers, technicians, procurement, and administrators

Assets Represented

  • HVAC Units
  • Boilers & Chillers
  • Electrical Panels & Generators
  • Elevators
  • Fire Suppression Systems
  • Security Systems
  • Roof Systems
  • Plumbing Systems

Risk & Intelligence Model

  • Risk Score = Asset Criticality × Health Degradation × Time-to-Failure
  • Predictive maintenance insights simulated on the client side
  • Logic designed to be consistent, believable, and actionable

Technical Implementation

  • React, TypeScript, and Next.js frontend architecture
  • Modern UI/UX and data visualization techniques
  • Internet-hosted prototype for demos and evaluation
  • Secure-by-design principles with documented deployment path
