# Senior Design Project Website

## Purpose
This website serves as the official project page for the senior design course. Its purpose is to document the project at a high level for academic review. It provides a clear overview of project goals, team composition, and submitted course deliverables.

## Project Overview
The project focuses on designing a user interface for an AI-driven facility management system. The website concisely defines the project’s objectives, scope, and constraints as required by the course.

## Website Requirements (Preliminary – Due 1/29)

### Main Page
The main page provides a concise definition of the project goals, including:
- What problem the project addresses
- What is being built at a high level
- The intended users and value of the solution

### Project Deliverables Page
A dedicated subpage contains all course deliverables organized by sprint.
- Preliminary presentation
- Sprint presentations
- Submitted documents and reports

This page acts as the central archive for all class-required materials.

### Team Page
A separate page presents information about the team members. Content is included at each member’s discretion and may include:
- Name
- Photo
- Short bio
- Contact information

## Scope Clarification
This website is for course documentation and evaluation only. It is not the deployed product, application UI, or backend system. Any references to implementation are descriptive, not functional.

## Status
Preliminary version created to satisfy initial course requirements. Content will be updated throughout the semester as deliverables are completed.
